Model

11 input features · MLP 11→16→8→4 · ReLU · Softmax · ArgMax · 1.9 KB ONNX · Opset 12

Confidence

Calibrated probability × familiarity. Raw softmax is never trusted alone. Temperature scaling T=2.0 baked into the ONNX graph.

Out-of-Distribution

KNOWN or UNKNOWN — unfamiliar workloads are protected, never acted on. Centroid-distance familiarity model.

Training

Pure NumPy / Adam

Model implemented using NumPy and exported to a hand-built ONNX graph. No sklearn/scipy dependencies.

Synthetic Data

87.38% synthetic fit — explicitly NOT real-world accuracy. No label leakage in final training.

ONNX Operators

Gemm · Relu · Softmax · ArgMax — four operators, 10 nodes, all verified on NPU.

AI Predicts. Safety Decides.

Safety Principles

  • Uncertainty causes more caution, not more aggressive optimization.
  • A real workload receiving zero optimization candidates is acceptable.
  • Model vote vs final decision are separate in code, API, UI, and logs.
  • Zero process-control code paths (audited).
  • Reversible by design — actions exist only as simulated projections.

Project Journey

Complete development timeline from system observation to competition submission.

Phase 1 — System Observation

VERIFIED

Implemented real system telemetry: CPU, RAM, disk, network, battery, uptime, live process list, platform detection, CPU architecture detection, foreground application detection, safety guard, dry-run optimization planner, and dashboard.

Phase 2 — AI Layer

VERIFIED

11-feature neural network (11→16→8→4, ReLU, Softmax, ArgMax). Pure NumPy/Adam training. ONNX export (1.9 KB, opset 12). Synthetic train/test: 93.22% train, 87.38% test.

Phase 2.5 — Calibration + OOD + Safety

VERIFIED

Removed protected-process label leakage. Temperature scaling T=2.0. Centroid-distance familiarity model for OOD detection. Four safety states: PROTECT, OBSERVE, REVIEW, OPTIMIZATION CANDIDATE.

Phase 2.7 — Low-Overhead Monitoring

VERIFIED

Tiered sampler with PID cache and reuse detection. Monitoring overhead reduced from ~6-8% bursts to ~1.0% steady CPU. ~70 MB RAM. Decision logging and history API.

Phase 3 — Safe Optimization Simulator

VERIFIED

Non-destructive simulation with four demo scenarios. Every result marked SIMULATED or PROJECTED. Zero process-control code paths.

Phase 4 — Qualcomm Snapdragon NPU Validation

FULLY NPU VALIDATED

Compile jp0m9yd0g, Profile jpxlrj1lp (10/10 NPU nodes), Inference j5wlrew3p (4/4 CPU/NPU agreement). Snapdragon X Elite CRD, Hexagon v73, Windows 11.

Final — Competition Package

SUBMITTED

Complete documentation, evidence, presentation materials, and submission checklist. All phases verified. Technical core frozen.

About

Independent competition prototype. Safety-first AI workload intelligence for Windows 11 on Snapdragon-powered HP PCs.

The system observes real workloads, understands workload behavior, predicts optimization opportunities, measures confidence and familiarity, becomes more conservative when uncertain, separates AI prediction from safety policy, never directly kills or modifies processes, and simulates optimization safely.

The ONNX model has been successfully validated on Qualcomm Snapdragon X Elite reference hardware with Hexagon NPU execution through Qualcomm AI Hub.

The technology is Snapdragon-targeted. The NPU model validation is real. The full HP end-to-end application still requires physical HP Snapdragon hardware.
